# Shared Package / Assets

This directory contains code, schemas, and configurations shared between services in the monorepo.

## Potential Uses

- **API Schemas & Contracts**: OpenAPI specs (`openapi.yaml`), Protocol Buffers (`proto/`), GraphQL schemas, or JSON Schemas.
- **Shared Types / DTOs**: Auto-generated types or client libraries for frontend and backend.
- **Shared Configs**: Common linting, formatting, or environment rules.
- **Static Assets**: Shared icons, brand assets, or common documentation.
